# SMS Laravel Eloquent Models

Generated for the agreed School Management System database architecture.

Contents:
- 69 Eloquent model files
- Fillable attributes derived from the corresponding migration fields
- Relationships derived from the agreed foreign keys / ERD
- Basic casts for booleans and JSON fields
- `ClassModel` represents the `classes` table because `Class` is a PHP reserved keyword.

Install:
Copy the PHP files into `app/Models/`.

Recommended next steps:
1. Install/configure Spatie Laravel Permission.
2. Add factories/seeders.
3. Add Form Requests.
4. Add service classes/business rules.
5. Add policies and controllers.
